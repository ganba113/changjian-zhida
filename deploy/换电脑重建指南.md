# 换电脑重建开发环境指南

换电脑后，本机的源码、依赖包、模型都需要重建。本文档给出完整步骤。

## 一、先分清：换电脑影响什么、不影响什么

| 内容 | 所在位置 | 换电脑后 |
|------|---------|---------|
| 源码 | git / GitHub | `git clone` 拉取即可 |
| 前端依赖 | `frontend/changjian-zhida/node_modules/` | `npm install` 重装 |
| Python 离线 wheel（45 个） | `backend/wheels/` | 拷贝 或 重新下载 |
| BGE 中文 embedding 模型（约 50MB） | `backend/vendor/bge/` | 拷贝 或 重新下载 |
| **LibreOffice / libstdc++ / chat.db** | **服务器** | **不受影响**（早已装好，无需重建） |

> 关键：服务器端（LibreOffice、数据库、系统库）已经部署好，换电脑只影响**本机开发环境**，服务器不用动。

## 二、完整重建步骤

### 1. 拉源码

```bash
git clone https://github.com/<你的用户名>/changjian-zhida.git
cd changjian-zhida
```

### 2. 安装前端依赖

```bash
cd frontend/changjian-zhida
npm install
cd ../..
```

### 3. 恢复 Python wheels（二选一）

**方式 A（推荐）：直接从旧电脑拷贝** `backend/wheels/` 整个目录（约 100MB），放到新电脑相同位置。

**方式 B：重新下载**（有网环境，需 Python 3.8+）：

```bash
python deploy/download_wheels.py
```

> 脚本用阿里云镜像下载 aarch64 + Python 3.9 的全部 wheel（主依赖 + OCR 依赖）。
> 若下载失败换镜像：`PIP_INDEX_URL=https://pypi.org/simple python deploy/download_wheels.py`

### 4. 恢复 BGE 模型（二选一）

**方式 A（推荐）：直接拷贝** `backend/vendor/bge/` 整个目录（约 50MB，含 `model_qint8.onnx` 和 tokenizer 文件）。

> 模型文件架构无关，Windows 下载的可以直接在 aarch64 服务器跑，跨电脑拷贝同样有效。

**方式 B：重新下载**（从 HuggingFace 国内镜像 hf-mirror）：

```bash
cd backend/vendor/bge
BASE="https://hf-mirror.com/onnx-community/bge-small-zh-v1.5-ONNX/resolve/main"
curl -L "$BASE/onnx/model_quantized.onnx" -o model_qint8.onnx
curl -L "$BASE/tokenizer.json" -o tokenizer.json
curl -L "$BASE/vocab.txt" -o vocab.txt
curl -L "$BASE/tokenizer_config.json" -o tokenizer_config.json
curl -L "$BASE/special_tokens_map.json" -o special_tokens_map.json
curl -L "$BASE/config.json" -o config.json
```

> 注意：下载后确认文件名与 `backend/main.py` 中 `KB_EMBED_MODEL_DIR` 引用的模型文件一致（默认 `model_qint8.onnx`）。
> 若文件名不同，改 `.env` 的 `KB_EMBED_MODEL_DIR` 或重命名文件。

### 5. 构建前端 + 打包部署包

```bash
cd frontend/changjian-zhida
npm run build          # 产物到 frontend/changjian-zhida/dist
cd ../..
python deploy_package.py   # 产出 changjian-zhida-deploy.zip
```

### 6. 部署到服务器（和平时一样）

```bash
# 服务器上
cp /opt/changjian-zhida/backend/chat.db /opt/chat.db.bak   # 先备份
cd /opt && unzip -o changjian-zhida-deploy.zip
cd /opt/changjian-zhida && bash deploy/install.sh
```

## 三、开发环境依赖清单

换电脑后的开发环境需要：

| 工具 | 版本 | 用途 |
|------|------|------|
| Node.js | 18+（本机用 22） | 前端构建 |
| Python | 3.8+（本机用 3.13） | 打包脚本、下载脚本 |
| Git | 任意 | 版本管理 |
| （可选）Codex CLI | `npm i -g @openai/codex` | AI 编码助手 |

> 后端完整联调仍需在 aarch64 服务器上做（本机 wheels 是 aarch64+py39，Windows 装不上）。

## 四、注意事项

1. **备份清单**：换电脑前，务必先把下面两个目录拷出来（或确认能重新下载）：
   - `backend/wheels/`（45 个 wheel）
   - `backend/vendor/bge/`（BGE 模型）
2. **不要依赖服务器上的文件**：服务器上只有部署后的产物，没有 wheels/模型源文件，别指望从服务器倒腾回来。
3. **敏感信息**：`.env`（含 vLLM 地址、管理员密码）在 git 之外，换电脑后需按 `deploy/README.md` 重新生成或手动补。
